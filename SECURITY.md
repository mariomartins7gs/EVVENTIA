# Sicurezza

Questo repository non deve contenere credenziali, configurazioni operative o dati personali.

Per segnalare un problema, contattare `[SECURITY_CONTACT]`. Non inserire in issue pubbliche token, URL firmati, dati cliente, identificativi di ambiente o istruzioni di accesso.

## Ambienti ed esempi

- usare `[API_BASE_URL]` al posto di host reali;
- usare `[ENVIRONMENT_NAME]` al posto di nomi o ID di ambiente;
- usare esclusivamente dataset sintetici;
- revocare e rimuovere dalla cronologia qualsiasi segreto pubblicato accidentalmente.
